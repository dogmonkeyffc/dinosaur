# Dinosaur App

Android 手机版与电视版使用 Kotlin 原生界面和 Media3。手机模块在 `apps/mobile-native/app`，电视模块在 `apps/tv-native`，共享网络、设备会话和字幕解析代码在 `apps/android-common`。Web 工程在 `ui/`。

当前版本交付 Android 手机和 Android TV / Google TV 两个客户端。三星 Tizen、LG webOS 不能安装 Android TV APK。

## 登录流程

1. 在已登录的 Web 中进入“账户安全”，检查登录账号，点击“生成配对码”获取 8 位数字码。
2. 手机 App 点击“配对码登录”，选择局域网发现的服务器或手动输入地址，再输入 8 位码。也可扫描 Web 登录二维码。配对码和二维码两分钟有效、只能兑换一次，互相刷新会废止上一份凭证；退出原 Web 会话、改密或禁用账号均使未兑换凭证失效。
3. 手机可以保存多个服务器/账号，在“切换账号”中选择本次要用于电视登录的账号。
4. 电视 App 启动后通过 `_dinosaur._tcp.local.` 自动查找局域网服务器，选中服务器后展示六位数字配对码。也可手动填写服务器地址。
5. 手机选择“登录电视”，输入六位码，确认目标电视名称和当前账号后授权。电视轮询取得独立设备会话并进入媒体列表。配对码五分钟有效，不能单独用于领取登录 Token。

电视刷新配对码或退出配对页时会撤销旧请求。手机和电视离线退出会先清除本机账号；未能联系服务器时，原设备会话仍可从 Web 撤销或等待到期。

手机和电视均支持电影、剧集和普通视频浏览、搜索、选集、原片播放、兼容模式、观看进度、下一集、音轨与字幕选择。内嵌文字字幕由服务端分段转换，PGS 等图片字幕通过兼容转码显示。ASS 字体与特效不保留。进入影片时自动选择中文，其次英语，下一集重新自动选择字幕。

Web“已登录设备”可单独退出手机或电视；改密和禁用账号撤销其全部会话。电视授权使用手机当前账号，客户端不能指定任意用户 ID 或提升角色。

## 网络

服务端新增 `DINOSAUR_SERVER_NAME`（默认 Dinosaur）和 `DINOSAUR_DISCOVERY_ENABLED`（默认 true）。监听回环地址时不发布发现信息；局域网部署应绑定 LAN 地址或 `0.0.0.0`。发现信息在启用组播的私有 IPv4 网卡上发布，需要同一局域网允许 UDP 5353；跨 VLAN、访客 Wi-Fi 和部分模拟器不能传递组播，可用手动连接。

手机通过发现服务公布的局域网 IP 连接，也支持手动输入公开 HTTPS 地址。电视优先尝试发现信息中的 `DINOSAUR_PUBLIC_URL`，连接失败时再尝试局域网 IP。配对码仅在创建它的服务器上有效。

HTTPS 必须使用设备信任的证书。局域网测试可直接使用 `http://192.168.x.x:端口`；App 会显示该连接使用 HTTP。HTTP 地址只接受私有 IPv4、回环地址及 `.local` 主机，其他主机必须使用 HTTPS。自定义域名在 Android 上还需要对应 DNS 解析，手机浏览器信任的私有证书不一定被原生 App 信任。

## 开发

原生客户端开发使用 JDK 17、Android SDK Platform 36 和工程自带的 Gradle Wrapper。在 `apps/mobile-native` 中运行：

```sh
./gradlew :app:assembleDebug
./gradlew :tv:assembleDebug
```

覆盖安装应使用与旧版相同签名的 release 包。旧客户端源码可在 Git 历史的 `92f7f0f` 提交中查阅。

## Android 安装包

构建需要 JDK 17、Python 3 与 Android SDK Platform 36。设置 `ANDROID_HOME`，并通过 `DINOSAUR_ANDROID_KEYSTORE` 或 `DINOSAUR_TV_KEYSTORE` 指定相应用途的已有签名密钥。

```sh
scripts/build_apps.sh all
scripts/build_apps.sh mobile
scripts/build_apps.sh tv
```

手机安装包版本取自 `apps/mobile-native/app/build.gradle`，电视安装包版本取自 `apps/tv-native/build.gradle`。安装包与 SHA-256 文件输出到 `bin/apps/`。

NAS 安装包统一发布到 `/mnt/eight/apks/`（文件管理器中为 `/eight/apks/`），保留版本号与对应 SHA-256 文件。新版发布并校验后，将同一客户端旧版安装包及其校验文件移到 `archive/`。

Go 服务仍通过根目录 `build.sh` 打包，不需要 Android SDK。App 要求服务端支持 `/api/server`、设备会话及配对 API；旧版 NAS 服务需升级后才能使用这些登录功能。

构建缓存、APK 和本机凭据不提交到 Git。

新增内嵌字幕功能需要同时升级服务端并重新构建手机/电视 APK；旧的 preview 安装包未包含图片字幕切换与分段续载适配。

## 0.6.1 手机界面密度

首页、片库、观看记录与账号设置采用 0.85 倍视觉尺寸，统一缩小文字、图标、固定卡片与间距，保留屏幕自适应宽度和系统安全区。新版为 0.6.1 / versionCode 8，仅更新手机 APK。

## 0.6.0 观看记录

第三个 tab 改为“记录”，展示当前账号的观看时间轴、评分与短评，支持分页加载、下拉刷新和详情。搜索保留在首页搜索栏。需要同步更新服务端以支持观看记录 API；新版为 0.6.0 / versionCode 7。导入工具、数据保存方式及 API 见 [观看记录](../docs/watch-history.md)。

## 0.5.0 手机设置与片库

头像入口打开账号与设置面板，可切换账号、登录电视，以及通过“首页显示”逐个开关媒体库。设置保存在本机并按服务器与账号隔离；只影响首页标签、封面及继续观看，片库和搜索仍可访问全部媒体库。全部关闭时首页显示空状态，重新开启后恢复。

片库页采用独立的大图头部、媒体库分类及纵向列表，支持详情和分页；搜索页保留原有网格与搜索功能。新版为 0.5.0 / versionCode 6，仅修改手机版。

## 0.4.0 手机首页

手机首页采用深色搜索栏、媒体库下划线标签、横向海报分区与大幅封面卡片；底部可切换首页、片库和搜索。保留账号菜单、下拉刷新、分页及继续观看。新版为 0.4.0 / versionCode 5，电视端与 Web 界面不变。

## 0.3.1 手机全屏横屏

手机播放器点击原生全屏按钮后固定横屏，退出全屏后返回原播放页面。新版为 0.3.1 / versionCode 4，需要更新手机 APK。

## 0.3.0 手机配对码登录

手机新版为 0.3.0 / versionCode 3。Web 发码接口 `POST /api/devices/login-code` 仅接受浏览器会话与 CSRF；公开兑换接口 `POST /api/devices/login-code/exchange` 接受 `{code,name}`。数字码只保存 SHA-256，不与电视 6 位码混用，兑换限每 IP 10 次及全局 100 次/15 分钟，包含无效尝试。成功生成独立设备会话，可从 Web 撤销。

模拟器通常无法接收 LAN mDNS 组播；使用 `http://10.0.2.2:端口` 连接开发机测试服务，或手动填写 NAS 私网地址。真机自动发现仍需同 Wi-Fi/组播环境验收。相同服务器 ID 与账号已有另一地址时，先退出原账号再更换地址，避免发现结果自报 ID 导致凭据转发或静默覆盖。

## 0.2.0 浏览同步

手机与 Android TV 现支持 Web 创建的作品分组：目录点击作品进入篇章封面，再进入季度封面与分集。特别篇显示为“特别篇”；不同篇章各自保留季号和元数据，不合并同名第一季。分组创建、改名和成员维护仍在 Web 完成，App 仅浏览。

播放器退出后保留之前的篇章、季度、滚动位置及 TV 返回焦点，硬件返回按分集、季度、篇章、目录逐层返回；切换账号时清空该账号的导航状态。剧集继续观看及原生音轨、文字/图片字幕适配仍保留。Web 的播放器菜单 CSS 不用于原生 App。

新版为 0.2.0 / Android versionCode 2，包含 arm64-v8a 与 x86_64，沿用旧预览包的签名和包名，可覆盖安装。需服务端包含作品分组 API；没有分组的旧剧集仍可直接浏览季度。正式分发仍需替换模板调试签名。

本次验证为 TypeScript 检查、客户端协议测试及手机/TV 的 release APK 编译和签名校验；没有宣称完成新版本真机验收。复用已有原生工程构建时保留 keystore；`prebuild --clean` 会重建原生目录，应先备份签名并校验新包证书，避免无法覆盖旧包。

## 初版验证范围

已在 Android 模拟器验证 Web 二维码载荷登录、手机多账号切换、手机授权电视登录、受保护的封面与视频播放、观看进度回传；已通过局域网查询验证服务端 mDNS 广播。自动化检查覆盖设备会话隔离、一次性兑换、并发兑换、配对过期与撤销、CSRF 及账号权限。

手机摄像头实际扫码、真实 Android TV 的遥控器体验及同一 Wi-Fi 下的自动发现仍需真机验收。模拟器网络不能传递组播，模拟器电视登录使用了手动服务器地址。
# 手机观看记录设置

0.7.0 可在账号设置的「记录观看」中按媒体库关闭自动记录。设置按账号保存在服务器，与 Web 观看记录页的「记录设置」同步；首页显示设置保持独立。关闭后不保存或展示播放进度及已看状态，不出现在继续观看中；关闭时自动清理该账号、该媒体库的旧进度和站内自动记录，重新开启不会恢复；手动记录与导入不受影响。

## 手机 0.8.0

账号切换与电视授权页统一使用手机版深色卡片。播放器提供自定义控制条、可拖动进度、横屏全屏和下一集按钮，播放结束自动切集，跨季切换保留全屏方向。进度保存失败不阻止切集，最后一集和普通视频不显示无效的下一集入口。

媒体库新增“普通视频”，按完整文件名展示，不识别电影年份或剧集季集，不参加影视刮削。Web 可创建和编辑此类型，手机可从媒体库标签浏览、搜索与直接播放；首页显示与观看记录设置继续按库生效。

## 手机 0.9.0

手机返回按钮采用透明箭头，播放器对齐 Web 的黑色画布、渐变浮层、绿色进度条和底部图标控制条，音轨、字幕、播放方式、分辨率与倍速使用弹出选项；保留横屏、自动连播及下一集。

管理员可从头像设置的「管理」进入 App 内管理页，使用当前账号管理媒体库、扫描、刮削、用户与访问权限及系统设置。普通账号没有管理入口，服务端仍验证管理员权限。App 使用 60 秒一次性登录码建立独立的管理会话，不把设备令牌交给页面；管理会话最多一小时，受手机会话有效期限制，关闭页面或撤销设备会话时失效。
