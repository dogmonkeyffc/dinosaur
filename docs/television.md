# 电视剧媒体库

管理员在“媒体库设置”中选择“电视剧”，填写服务器目录。保存后自动扫描，服务重启时也会扫描已有电影和电视剧媒体库。媒体库卡片和“我的剧集”均可手动启动扫描。

## 命名与归集

推荐每部剧使用独立目录，季度目录可选：

```text
TV/
  Example (2020)/
    Season 01/
      Example.S01E01.Pilot.mkv
      Example.S01E02.mkv
    Season 02/
      Example.S02E01.mkv
    Specials/
      Example.S00E01.mkv
```

识别不区分大小写的 `S01E01` 和 `1x01`。季编号 0 用于特别篇，集编号从 1 开始。同一文件包含连续两集时可用 `S01E01E02` 或 `S01E01-E02`；它作为一个播放文件保存进度，“下一集”跳过已包含的编号。其他连续集范围、多段范围和仅有日期的命名暂不支持。

存在剧名目录时按目录归集，忽略 `Season 01`、`S01`、`Specials`、`特别篇`、`第1季`等季度目录；同一媒体库根目录中的平铺文件按解析后的剧名与年份归集。不同媒体库保持独立。同一季度的不同编码版本会分别展示，由用户选择，不自动丢弃重复集号。

文件未提供季集编号时跳过并计入扫描问题数，日志记录文件位置；不会猜测集号。损坏但能识别季集编号的视频仍入库，详情提示媒体信息不完整。扫描支持的文件格式、路径限制、符号链接规则和工具超时沿用电影扫描。

同一路径重复扫描保持媒体文件和剧集 ID、观看记录与已匹配资料。完整遍历成功后隐藏缺失文件；目录不可访问时保留已有索引。所有单集缺失后，剧集不再出现在列表中，文件恢复后继续使用原记录。修改媒体库类型或根目录会清理旧索引，原始文件不会被删除。

## 浏览与播放

“我的剧集”支持剧名/别名搜索、媒体库筛选和分页。详情地址为 `/series/{id}`，按季度列出本地单集，可查看文件、音轨信息，播放、继续观看、从头播放和标记已看。

每个文件复用现有播放器、音轨、外挂字幕、原文件 Range、转封装和兼容转码。进度按用户与媒体文件独立保存，达到时长的 90% 自动标记已看。播放器提供“下一集”，正常播放结束后自动播放下一集，支持跨季并跳过缺失文件。特别篇不会插入正片季度之间。

继续观看按每部剧展示一个入口：优先最近未看完的文件，其次最近观看位置之后的未看单集，再选择其他未看单集。新剧默认从正片第一季开始，特别篇可在季度选择中播放。全部已看后不再显示继续观看入口。

## TMDB 资料

使用现有元数据设置中的凭据和语言。扫描完成后，独立的剧集后台任务处理未匹配剧集；每部剧只获取一次整剧资料，不按单集重复刮削。电影和剧集分别限制为一个刮削任务，历史记录中标明类型并保留结果快照。

自动匹配沿用已知年份与唯一候选规则。剧名或首播年份不足以确定时，管理员可在剧集详情搜索候选或指定 TMDB **剧集** ID；电影 ID 和剧集 ID 属于不同命名空间。已匹配资料只在主动刷新或更正时重新获取，刷新失败保留原资料。中文译名、简介、原名、别名和整剧海报可用；每季海报、单集线上标题与剧情资料暂不读取。

“刮削管理”的影片状态统计仍针对电影；任务历史包含电影和剧集，剧集结果可打开剧集详情进行更正。剧集列表中的任务状态会自动更新。

TMDB 实现参考官方 [TV 搜索](https://developer.themoviedb.org/reference/search-tv)、[TV 详情](https://developer.themoviedb.org/reference/tv-series-details)和[翻译](https://developer.themoviedb.org/reference/tv-series-translations)接口。

## API

所有读取接口要求登录；所有管理接口要求管理员，会改变状态的请求另需 CSRF Token。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/series` | 剧集分页，支持 `q`、`library_id`、`page`、`page_size`；返回本地季度、文件和已看数量 |
| GET | `/api/series/{id}` | 剧集资料、分季单集及当前用户的推荐播放入口 |
| GET | `/api/series/{id}/poster` | 登录保护的本地海报 |
| GET | `/api/playback/continue?type=tv` | 当前用户按剧集归并的继续观看；省略 `type` 仍返回电影 |
| GET | `/api/playback/{id}` | 单集使用媒体文件 ID；额外返回 `next_episode` |
| POST | `/api/admin/tv/metadata/jobs` | 刮削未识别剧集，支持 `library_id`；单剧支持 `series_id`、`refresh` 或 `tmdb_id` |
| GET | `/api/admin/tv/metadata/jobs` | 剧集刮削历史，支持分页和状态筛选 |
| GET | `/api/admin/series/{id}/metadata/candidates` | 剧集候选，支持 `q`、`year`（0 不限年份） |

剧集单集的进度、流和字幕仍使用 `/api/playback/{媒体文件ID}/...`；剧集 ID 只用于剧集资料与分季浏览。电影列表 `/api/media` 和默认电影继续观看不会混入电视剧。

新增迁移 `009_television.sql`，保留原电影索引和观看记录。上线前按现有部署说明备份数据库；旧程序不支持浏览新增的剧集表。
