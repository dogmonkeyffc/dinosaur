# Sketch 视觉规范

Web 使用统一的草稿纸主题，入口为 `src/styles/sketch.css`。保留现有 React 组件、路由和交互；页面结构和业务逻辑不承担主题职责。

- 暖纸底色、深色铅笔墨迹、蓝色辅助操作、红色主操作、黄色选中高亮。
- 全局颜色、字体、描边、圆角与动效统一使用 `sketch-tokens.css` 中的 `--dp-*` 变量；旧变量映射到同一套颜色。
- 标题采用较粗的手写字体，正文采用易读的手写或楷体。原设计的 Working Sheet 字体未提供，当前使用系统 Segoe Print / Comic Sans MS 与中文楷体，缺失时回退到衬线字体；不分发系统字体文件。路径与密集表格使用直立字体。
- 中文正文 23px，普通控件及标签 21px，标题 30–42px。密集数据允许缩小，但应保持清晰可读。
- 控件用细线、不规则圆角和少量硬偏移阴影；用选中高亮与明确描边表达状态。
- 海报保留原始色彩与比例，用纸边及少量胶带装裱。装饰使用 CSS 伪元素，不添加可读内容，不捕获点击。
- 保持开放留白，不增加宣传语、教学段落、重复标签、装饰性说明或虚构内容。必要帮助放在全局 InfoTip 中。
- 手机保留顶部菜单，海报双列，筛选控件允许整行排列。避免整体旋转和装饰导致横向溢出。
- 原生按钮、链接、表单与折叠语义不变；键盘焦点采用蓝色虚线。悬停及按压变化限于 100ms，减少动态效果模式关闭动画和装饰变换。
- 视频播放器保持深色、高对比度及直立字体，避免纸张装饰影响观看和操作。

主题按 tokens、controls、shell、surfaces、catalog 拆分；新增同类组件应复用对应样式，不复制一套主题。
